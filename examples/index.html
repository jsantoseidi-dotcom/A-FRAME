03 · Como contribuir

  1. Consultar a documentação e a licença do componente original.
  2. Criar uma pasta com o nome do componente.
  3. Adicionar uma demonstração mínima e outra interativa.
  4. Documentar dependências, propriedades, eventos e versão testada.
  5. Validar no browser antes de alterar o estado para funcional.

Versão base da demonstração: A-Frame 1.8.0. Componentes externos podem exigir versões ou dependências diferentes.
