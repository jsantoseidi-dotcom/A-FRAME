# particle-system

Sistema comunitário para emitir partículas numa cena A-Frame.

- Pacote: `@c-frame/aframe-particle-system-component`
- Versão fixada: `1.2.0`
- Licença indicada no npm: MIT
- A-Frame usado no exemplo: `1.8.0`
- Demonstração: [abrir index.html](./index.html)

## Demonstração

O exemplo usa o preset `rain`, define `particleCount` e personaliza as cores.

## Dependências

```html
<script src="https://aframe.io/releases/1.8.0/aframe.min.js"></script>
<script src="https://unpkg.com/@c-frame/aframe-particle-system-component@1.2.0/dist/aframe-particle-system-component.min.js"></script>
```
