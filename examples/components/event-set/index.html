event-set

Move o cursor sobre o cubo para o destacar. Clica no cubo para aumentar a escala e alterar a cor.

O que demonstra

  • mouseenter e mouseleave para alterar a cor.
  • click para alterar propriedades de material e escala.
  • Instância do componente declarada diretamente nos atributos HTML.

Dependências: A-Frame 1.8.0 e aframe-event-set-component 5.1.0.

Estado: exemplo criado com base na API documentada; falta validação manual em browser/dispositivo XR.
